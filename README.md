# WoW Forever Kit

One file sets up WoW Forever with the addons I use.

**[Download Install.bat](https://github.com/jackisgolden/wow-forever-kit/releases/latest/download/Install.bat)**

---

**1. Close WoW.**

**2. Download the file above.** Your browser may ask if you want to keep it. Click Keep.

**3. Double-click it.** Windows may show a blue box saying it protected your PC. Click More info, then Run anyway. A black window lists each addon as it installs, which takes a few seconds.

**4. Start WoW.** On the character screen, click AddOns and make sure they are all ticked.

To update, run the same file again. Your settings stay put.

---

**What you get**

Your first login sets everything up. You will see a green line in chat when it is done.

Four rows of buttons sit low in the middle of your screen, and each row matches your keyboard:

| Row | Keys |
|---|---|
| 1 | 1 2 3 4 5 6 |
| 2 | Q E R F C V |
| 3 | G Z X Y H ` |
| 4 | Shift + 1 2 3 4 5 6 |

Drag spells from your spellbook onto the buttons. Put what you press most on row 1.

A and D now strafe, which means you sidestep instead of turning. Turn with your mouse. It feels strange for a few days and then it is much faster.

T talks to whatever you are looking at. Shift+C opens your character. B opens your bags.

To reset your layout, type `/forever` in chat.

---

**Your addons**

| Addon | What it does |
|---|---|
| Questie | Shows quests on your map. |
| RestedXP | Tells you where to go next. Free to about level 20. |
| Bartender4 | Your action bars. Type `/bt` to change them. |
| SexyMap | Your big square minimap. Type `/sexymap` to change it. |
| Bagnon | All your bags in one window. |
| Auctionator | Makes the Auction House usable. |
| Leatrix Plus | Small fixes the game should have had. Type `/ltp`. |

---

**If something breaks**

| Problem | Fix |
|---|---|
| It says WoW was not found | Install WoW Forever from Battle.net first. |
| It says it cannot write to the folder | Right-click Install.bat and pick Run as administrator. |
| An addon says FAILED | Run the file again. |
| A red error in chat | Run the file again, then fully quit and reopen WoW. |
