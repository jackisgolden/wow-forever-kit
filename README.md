# WoW Forever Kit

One file sets up WoW Forever with the addons I use.

**[Download Install.bat](https://github.com/jackisgolden/wow-forever-kit/releases/latest/download/Install.bat)**

---

**1. Close WoW.**

**2. Download the file above.** Your browser may ask if you want to keep it. Click Keep.

**3. Double-click it.** Windows may show a blue box saying it protected your PC. Click More info, then Run anyway. A black window lists each addon as it installs, which takes about a minute.

**4. Start WoW.** On the character screen, click AddOns and make sure they are all ticked.

To update, run the same file again. Your settings stay put.

---

**Set yourself up**

Type these in the chat box. Each one opens a settings window, so play with them until the game feels right.

| Type this | What it does |
|---|---|
| `/lime` | Picks a leveling guide. It tells you where to go and what to do next. |
| `/bt` | Moves and reshapes your action bars. |
| `/ltp` | Leatrix Plus: dozens of small fixes the game should have had. |
| `/ltm` | Leatrix Maps: shows the whole map, including places you have not been. |
| `/questie` | Quest markers on your map and minimap. |
| `/details` | Damage meter options. |
| `/al` | AtlasLoot: what every boss drops. |

These work without a command:

| Addon | What it does |
|---|---|
| Bagnon | Puts all your bags in one window. Press B. |
| Auctionator | Makes the Auction House usable. Open the Auction House to see it. |
| GatherMate2 | Remembers every herb and ore node you find. |
| Prat | Cleans up the chat window. |
| WeaponSwingTimer | Shows when your next auto-attack lands. |
| UnitScan and Safeguard | Warn you about dangerous enemies and help you stay alive. |

---

**If something breaks**

| Problem | Fix |
|---|---|
| It says WoW was not found | Install WoW Forever from Battle.net first. |
| It says it cannot write to the folder | Right-click Install.bat and pick Run as administrator. |
| An addon says FAILED | Run the file again. |
| A red error in chat | Run the file again, then fully quit and reopen WoW. |
