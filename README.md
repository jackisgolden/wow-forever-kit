# WoW Forever Kit

One file sets up WoW Forever with the addons I use.

**[Download Install.bat](https://github.com/jackisgolden/wow-forever-kit/releases/latest/download/Install.bat)**

---

**1. Close WoW.**

**2. Download the file above.** Your browser may ask if you want to keep it. Click Keep.

**3. Double-click it.** Windows may show a blue box saying it protected your PC. Click More info, then Run anyway. A black window lists each addon as it installs, which takes a few seconds.

**4. Start WoW.** On the character screen, click AddOns and make sure they are all ticked.

To update, close WoW and run the same file again. Your settings stay put, and addons I removed from the kit get removed for you.

---

**What you get**

Your first login sets everything up. You will see a green line in chat when it is done.

Three rows of 12 buttons sit along the bottom of your screen. Your normal WoW keys all still work.

| Row | Keys |
|---|---|
| Bottom | 1 to 0, - and = |
| Middle | Alt + the same keys |
| Top | Ctrl + Shift + the same keys |

Drag spells from your spellbook onto the buttons. Put what you press most on the bottom row, and things you use less on the rows above.

A faded bar on the right edge is for things like your Hearthstone and food. It lights up when you hover over it, and its first six buttons are Alt + Q, E, R, F, C and V.

Enemies show health bars above their heads, and your gear repairs itself when you open a repair vendor.

Your health card and your party's cards sit near the middle of the screen, with your party stacked above and to the left. Type `/ft` for the threat meter, which shows who is closest to pulling aggro.

Your spellbook has a tab listing every spell you can learn and what it costs. Your map shows trainers and vendors, and `/fv` sets which ones.

[GUIDE.md](GUIDE.md) shows which job goes on which key, for any class.

The minimap has no addon icons. Type these in chat to open each addon's settings:

| Type | Opens |
|---|---|
| `/bt` | Action bars |
| `/ltp` | Leatrix Plus, for game tweaks |
| `/ft` | Threat meter |
| `/wt` | Spells you can learn |
| `/fv` | Trainers and vendors on the map |

To reset your layout, or fit it to a new monitor, type `/forever` in chat.

---

**Your addons**

| Addon | What it does |
|---|---|
| Questie | Shows quests on your map. |
| RestedXP | Tells you where to go next. Free to about level 20. |
| Bartender4 | Your action bars. Type `/bt` to change them. |
| SexyMap | Your big square minimap. Type `/sexymap` to change it. |
| Bagnon | All your bags in one window. |
| Auctionator | Makes the Auction House usable. |
| Leatrix Plus | Small fixes the game should have had. Type `/ltp`. |

---

**If something breaks**

| Problem | Fix |
|---|---|
| It says WoW was not found | Install WoW Forever from Battle.net first. |
| It says it cannot write to the folder | Right-click Install.bat and pick Run as administrator. |
| An addon says FAILED | Run the file again. |
| A red error in chat | Run the file again, then fully quit and reopen WoW. |
