# Playing any class

Every class fits the same buttons, so a new character never means new habits. Keep each job on the same key, and swap in that class's spell.

| Key | Job |
|---|---|
| 1 | The attack you press most |
| 2 | Your second attack |
| 3 | The attack on a short cooldown |
| 4 | Ranged attack or pull |
| 5 | Stun or crowd control |
| 6 | Hits many enemies |
| Alt + 1 | Heal or self-care |
| Alt + 2 | Interrupt |
| Alt + 3 | Your big defensive cooldown |
| Alt + 4 | Save a friend, or escape |
| Alt + 5 | Remove a curse, poison, or disease |
| Alt + 6 | Taunt or threat, if your class has one |

Keep rarely used things on the top row, with Ctrl + Shift. Buffs, stances, and mounts live there. Food, water, and your Hearthstone go on the faded bar, on Alt + Q, E, R, F, C and V.

Leave a key empty until your class learns something for it. At level 60 you will still be using the same keys.

## Leading a group

Type `/ft` to see the threat meter. It shows who is closest to pulling aggro.
